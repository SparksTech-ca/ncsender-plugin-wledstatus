↔️ X-Axis Follower
Pick which of your configured instances shows the moving cursor. An instance already assigned to another effect below won't appear here — each instance can only run one exclusive effect at a time.
Should match the actual physical LED count of whichever instance you picked above.
Nudges the whole mapping if the cursor sits consistently ahead of or behind the true spindle position — e.g. if it reads 15mm too far in one direction, enter -15 (or +15) to correct it. Covers any systematic misalignment, whatever the cause (carriage geometry, strip mounting, coordinate origin).
Leave the travel override blank to use $130 if available.
📊 Job Progress
Pick one of your configured instances to display the fill bar on. That instance shows the progress bar only while a job is running, and its normal status color the rest of the time. An instance already assigned to the X-axis follower won't appear here.
Should match the LED count of whichever instance you picked above.
Used for gradient fill, and ignored for solid fill (start color is used as the single fill color).
